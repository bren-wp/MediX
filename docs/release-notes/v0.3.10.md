# MediX v0.3.10

A clearer medicine search for clinicians and patients, with conservative reimbursement and pricing semantics.

## Faster medicine lookup

- One-tap search filters for prescription-only medicines, non-prescription products, HZZO Basic List, HZZO Supplementary List and verified HZZO copayments.
- Search combines quick filters with the existing free-text and professional filters.
- Croatian and English filter descriptions; fallback remains English for other languages.
- A medicine without a confirmed HZZO reimbursement match is **unverified**, never asserted to be excluded.

## Trustworthy price comparison

- HZZO copayments and maximum wholesale prices now have independent ascending and descending sort options. These are not interchangeable prices.
- Search filters use the same finite, nonnegative EUR validation as the price overview.
- The HZZO copayment filter includes only prices explicitly associated with a confirmed Supplementary List match.
- Missing amounts sort after known amounts for the specific selected price kind.
- No claimed patient out-of-pocket cost under personal supplementary insurance and no invented pharmacy retail prices.

## Stability

- If opening the official HZZO link fails because no browser handler is available, the medicine screen remains usable and shows a localized explanation.
- Regression coverage includes wrong reimbursement status, non-EUR/invalid amounts, separate copay vs wholesale sort, unknown HZZO status, Croatian one-tap filters and browser-handler failures.

## Data sources

HZZO published medicine lists: https://hzzo.hr/zdravstvena-zastita/objavljene-liste-lijekova

Official records represent their published effective dates; the app does not claim continuous real-time price changes or instant medicine availability.

## Build and release verification

Merge and publish only after successful Flutter analyze, all tests, Dart reachability audit, debug APK and release APK/AAB on the final PR SHA. Public GitHub artifacts are **not** equivalent to a separately privately signed production Google Play package.
