# MediX v0.3.6

MediX v0.3.6 strengthens the privacy of personal therapy exports and gives the product a clearer, more polished public identity.

## More secure personal exports

- ZIP exports now live in their own dedicated application cache directory.
- Android's FileProvider shares **only** that directory, not the entire cache.
- Share requests reject non-MediX files, unexpected extensions, and paths outside the export directory, including canonical-path bypasses.
- Previous MediX export archives older than 24 hours are cleaned up when a new export is prepared.
- No broad file-storage permissions or MediX cloud upload are needed.

## Product experience

- README redesigned into an English-first, premium product showcase.
- Existing authentic brand visuals retained; no screenshots or product imagery have been invented.
- Medicine information and interaction-safety wording stays appropriately qualified.
- Links opened through MediX's Android navigation channel require HTTPS.

## Quality gates

- Flutter analyze and automated test suite
- Export privacy regression tests
- Android debug build
- Android release APK and AAB verification
- Published release assets and SHA-256 checksums

## Version

MediX 0.3.6+9

## Signing and store eligibility

GitHub release candidates remain distinct from a privately signed Google Play submission. A Google Play production upload requires a real private upload key in the protected signing workflow and completion of Play Console declarations. The repository currently contains an Android application, not a finished iOS/App Store target.
