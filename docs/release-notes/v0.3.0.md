# MediX v0.3.0

Prvo javno GitHub izdanje MediX-a.

MediX v0.3.0 pretvara projekt u ozbiljnu Android bazu lijekova i profesionalni klinički workspace, uz prepoznatljiv dark navy/cyan MediX dizajn i bez obvezne registracije.

## Najvažnije

- objedinjeni katalog lijekova i pakiranja
- pretraga po nazivu, djelatnoj tvari, ATK šifri, kategoriji i pakiranju
- MediX Smart pretraga prirodnim upitom
- ATK preglednik
- lokalni MKB-10 registar s 39.559 zapisa
- modul interakcija
- paralelni i srodni lijekovi
- cijene i pakiranja
- lokalni favoriti i nedavno pregledani lijekovi
- Moja terapija, kalendar i Android podsjetnici
- posebni prikazi za trudnoću/dojenje, djecu i starije osobe
- 9 kliničkih kalkulatora: BMI, BSA, eGFR MDRD, CHA₂DS₂-VASc, HAS-BLED, GCS, MELD, PERC i Wells PE
- novi MediX adaptive launcher icon
- potpuno marketinški README s MediX logom i vizualima

## Android datoteke

Release sadrži:

- `MediX-v0.3.0.apk` — instalacijski Android APK
- `MediX-v0.3.0.aab` — Android App Bundle
- `SHA256SUMS.txt` — SHA-256 provjera integriteta

## Kvaliteta

Prije objave workflow obavezno pokreće:

- `flutter analyze`
- `flutter test`
- release APK build
- release AAB build
- provjeru oba binarna izlaza

> MediX je informacijski alat. Medicinske informacije i kalkulatori ne zamjenjuju stručnu kliničku procjenu.
