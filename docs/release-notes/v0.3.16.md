# MediX v0.3.16

A medication data integrity release for clinician-first use. It reduces the risk of assigning HZZO list membership, copayments or wholesale prices to the wrong medicine presentation.

## Data integrity
- Secondary HZZO and price records must match the HALMED medicine's active ingredient, strength and package unit count.
- Identical trade names and ATC codes no longer override mismatching active ingredients.
- Incomplete package descriptions stay unverified rather than being matched optimistically.
- Simultaneous basic and supplementary HZZO flags are treated as contradictory and remain unverified.
- HZZO copayments are only stored for a supplementary-list record with a valid official effective date.
- Per-record contradictory currencies are rejected even when the source declares EUR.

## QA and compatibility
- New regression tests cover valid matching, ingredient mismatch, missing package or strength, ambiguous duplicate candidates, contradictory HZZO flags, basic-list copays and foreign-currency rows.
- Existing clinical search, accessibility, therapy, privacy and other automated tests remain in place.
- All application screens and the existing MediX identity are preserved.

## Release gates
The new release must pass all Flutter tests, flutter analyze, Dart production reachability audit, Android debug, release APK and AAB builds. Publish only after verifying the exact last commit and public GitHub artifact hashes.

**Version:** 0.3.16+19

MediX is an offline medicine reference, not a medical device certification, a live pharmacy price feed or an individualized reimbursement calculator. Verify official records before clinical use.
