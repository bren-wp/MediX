# MediX v0.3.12

MediX v0.3.12 makes medicine comparisons and wholesale-price browsing consistent with the verified reimbursement safeguards already used in medicine details.

## Safer side-by-side clinical comparisons

- Compare up to four medicines using the same validated EUR pricing rules as each individual medicine profile.
- Only show a HZZO copayment when a matched medicine belongs to the HZZO Supplementary List.
- Hide negative, non-finite, non-EUR, and unsupported price records in the comparison.
- Distinguish a missing HZZO list match from confirmed exclusion: missing matching evidence is **unverified**, not “not listed.”
- Show a HZZO effective date when available, and explicitly mark the date as unconfirmed otherwise.
- Clarify that maximum wholesale prices are not pharmacy retail prices.
- Reuse the prepared medicine search index for responsive comparison selection.

## Transparent published wholesale catalog

- The separate wholesale catalog validates all displayed EUR prices, accepting only finite nonnegative amounts.
- Missing, malformed or invalid source publication dates do not default to a fabricated date.
- Individual prices are visibly identified as “Na veliko” (wholesale).
- Retain unavailable values as unknown rather than presenting zero or unverified currency conversions.
- Prepare searchable record text once during catalog loading to avoid repeated concatenation while typing.

## Regression and release gates

- New tests verify Basic List copayment suppression, Supplementary List copay, unknown reimbursement, distinct wholesale price, invalid currency/values and unconfirmed dates.
- New tests verify valid, invalid, missing and impossible publication dates.
- Merge only after successful Flutter analyze, full test suite, Dart source reachability audit, debug APK, and release candidate APK and AAB from the same PR commit.
- Public GitHub APK/AAB/SHA256SUMS must be verified after merging to main.

## Medical data boundaries

The HZZO Supplementary List is distinct from a person's supplementary insurance policy. The HZZO copayment is linked to a specific original medicine package and is not a guaranteed individual pharmacy payment. Published maximum wholesale prices are not retail pharmacy quotes.

Official HZZO search: https://hzzo.hr/trazilica-za-lijekove
