# MediX v0.3.11

MediX v0.3.11 makes the clinical medicine search more efficient and documents the provenance of confirmed HZZO coverage without inventing effective dates.

## Faster medicine search

- Normalize and cache each medicine's search text once for the lifetime of the Search screen, instead of repeating the work on each keystroke.
- Tokenize the current search expression once per query, preserving diacritic-insensitive name, active ingredient, ATC, packaging and administrative-field matching.
- Preserve all professional filters and validated copayment/wholesale price sorting.
- Indexes use medicine object identity rather than potentially duplicated IDs, and safely fall back for new records outside the index.
- Regression tests compare cached vs uncached results across ordinary and complex clinical searches.

## HZZO evidence and date transparency

- For an exactly matched HZZO Basic/Supplementary List record, display its source label and officially supplied date from which that list applies.
- When no reliable effective date is supplied, the interface explicitly says the date is not confirmed.
- A copayment imported without an effective-date source is not assigned a fabricated valid-from date and does not appear as a dated HZZO copayment.
- Include confirmed HZZO list source/effective date in the copyable medicine summary.
- The date belongs to the HZZO list, not to a personal supplementary insurance policy or current pharmacy shelf price.

## QA scope

- Search regression tests covering names, diacritics, multiword queries, ATC codes, filters, sorting and new data outside the index.
- HZZO provenance tests for documented source dates, missing dates, and exact package matching.
- Mandatory gates: Flutter analyze, full test suite, production Dart reachability audit, CI debug APK, release candidate APK/AAB, and publication SHA-256 verification.

## Medical caveat

MediX is a reference application. It does not issue prescriptions, determine an individual patient's reimbursement entitlement, guarantee in-pharmacy availability, or invent retail pricing. Clinicians should verify prescribing rules and the current source documents before decisions.
