# MediX v0.3.7

MediX v0.3.7 improves therapy reminder consistency, input validation, catalog lookup performance and the clarity of Settings feedback.

## Therapy and reminder reliability

- Reminder refresh operations are serialized so a prior edit cannot recreate obsolete alarms after a newer change.
- Reminder times are validated and normalized to HH:mm before a therapy is saved, edited or restored from local preferences.
- Previously saved invalid times are ignored instead of being used for scheduling.
- Granting reminder permissions refreshes the current therapy plan.

## Premium everyday experience

- The therapy list uses lazy item rendering rather than creating every card up front.
- Medicine lookup by ID uses an indexed map, reducing repeated full-catalog scans.
- Settings notification-permission feedback is localized in English and Croatian, with an explicit English fallback for other supported languages.
- A platform exception during a permission request no longer leaves the Settings action permanently busy.
- The public README retains real brand assets and describes the current behavior accurately.

## Privacy transparency

- Settings, README and the exported app information now link to public, MediX-specific privacy and terms documents.
- The privacy policy explains the app-private SharedPreferences storage, user-directed ZIP sharing and when old cached exports are removed.

## Quality gates

This release is published only after the CI analysis, unit/widget tests, reachability audit and Android APK/AAB builds succeed. The published release assets include SHA256SUMS.txt.

## Version

MediX 0.3.7+10

## Distribution and medical safety

Android GitHub release candidates may be signed using the debug fallback; they must not be described as Google Play production-signed builds. The private Play signing workflow remains separate. MediX has no verified iOS/App Store build at this time.

MediX provides informational medicine data and does not replace professional medical advice. An absent interaction record is not evidence that a combination is safe.
