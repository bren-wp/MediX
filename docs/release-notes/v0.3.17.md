# MediX v0.3.17

This release improves verifiable catalog quality, on-device privacy resilience and Android usability without replacing the existing MediX visual identity.

## Official data integrity
- Every pull-request CI run validates the bundled HALMED, HZZO and wholesale price catalogs, not just synthetic fixtures.
- Secondary sources must have a named provenance, correctly formatted actual calendar dates and structurally valid records.
- Declared record counts cannot silently diverge from actual JSON contents.
- A non-mutating validation mode prevents an automated check from altering the checked-in data quality report.
- Unit tests for the validator run before every scheduled data sync.

## Stability, privacy and small screens
- A damaged local therapy entry no longer discards unrelated saved therapy records.
- Duplicate restored therapy IDs are ignored; malformed private fields are not printed to logs.
- The search count and advanced-filter control adapt to a narrow 320px screen and large Android text.
- Recent medication lists reuse the existing in-memory index to avoid repeated full-map allocations.

## QA / release gates
Release only after validator unit tests, validation of real bundled catalogs, Dart reachability audit, Flutter analysis, all Flutter tests, debug APK and release APK/AAB builds pass on the latest commit. Validate main branch workflows, public assets and release checksums after merging.

**Version:** 0.3.17+20

MediX is an offline reference and does not replace current official medicine documents, clinician judgment or individual reimbursement verification. Google Play signing and physical-device testing remain separate.
