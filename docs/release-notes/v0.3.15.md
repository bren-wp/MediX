# MediX v0.3.15

This release hardens date and price provenance for official medicine records without adding speculative clinical data.

## HZZO and HALMED data integrity
- Strict calendar-date validation prevents impossible source dates from being interpreted as confirmed HZZO effective dates.
- Wholesale prices require an explicit valid publication date. The old hard-coded fallback for missing dates is removed.
- Prices with invalid values or a contradictory source currency are rejected.
- Broken optional wholesale catalog JSON no longer prevents the main HALMED medication catalog from loading.
- HZZO copayment and wholesale amount parsing now share one conservative EUR validator; duplicated parsing logic was removed.

## Regression checks
- New tests cover valid pack-matched price imports, dates without official support, nonexistent dates, malformed price JSON, invalid price amounts, conflicting currency and invalid HZZO effective dates.
- Existing medicine search, medicine-pack matching, HZZO access, accessibility, clinical and security tests remain required.

## Release requirements
Only publish after Flutter analyze, all automated tests, the production Dart reachability audit, Android debug build and release APK/AAB build succeed on the latest PR commit. Check public release assets and SHA-256 checksums.

**Version:** 0.3.15+18

MediX remains an offline medical reference rather than an individual reimbursement determination, real-time pharmacy pricing feed or substitute for validated prescribing information.
