# MediX v0.3.14

A clinical usability and Android accessibility release. This version keeps prescription, HZZO reimbursement and confirmed copayment filters composable, while making home actions more robust on narrow phones and with enlarged text.

## Clinical medicine search
- **Independent one-tap filters:** toggling prescription-only or OTC does not reset selected HZZO list, validated copayment or advanced professional constraints.
- Basic List and Supplementary List quick chips switch reimbursement status without resetting dispensing, pricing, medicine form, ATC, market, shortages or holder filters.
- Tapping a selected chip clears **only its own filter category**.
- **All** clears all quick and advanced filters while retaining the free-text search and existing sorting choice.
- The All chip's selected state reflects any active advanced filters; it no longer incorrectly appears selected when hidden professional filters still apply.

## Small-screen accessibility
- The six home medicine actions, professional tools and categories now use responsive tile heights rather than fixed aspect ratios.
- Heights adapt to increased system font size, preventing vertically clipped labels on narrow Android displays.
- Existing home shortcuts and their destinations remain unchanged.

## Regression coverage
- Pure query tests verify combining prescription, HZZO and price filters preserves market, shortage, form, ATC and holder restrictions, as well as sorting and free-text.
- Widget test verifies two selected one-tap filters coexist and turning one off does not clear the other.
- 320px Android home-screen widget test with 1.7× text scaling and scrolling checks layout overflow and search shortcut.
- All existing medical data matching, HALMED dispensing, HZZO price and security tests remain active.

## Release gates
Do not merge until Flutter analyze, complete tests, Dart production-file reachability audit, debug APK, release APK and AAB all succeed on the latest pull-request SHA. After merging, verify the three main workflows and the public APK/AAB/SHA256SUMS digests.

## Boundaries
This app is an offline reference. It is not a real-time retail pharmacy price service or individual reimbursement calculator; its information should be checked against official product documents before prescribing or dispensing. Google Play private signing and testing on physical devices remain separate tasks.
